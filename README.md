A faster drop-in for make.fun's csv-reader 1.0.0: `solve.js` answers every
CSV case exactly as the reference does (`{columns, rows, errors}`), in one
indexOf-driven pass instead of a character at a time. `main.ts` reads every
case from `/input/cases.json` and writes `/output/answers.json`.
